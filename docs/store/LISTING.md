**Description:**
ByteBouncer is a modern FTP, FTPS and SFTP client built for one thing: moving files as fast as your connection allows.

Most FTP clients pull a file over a single connection, so a server that limits speed per connection — or a long-distance link with high latency — leaves most of your bandwidth idle. ByteBouncer splits large files into segments and downloads them over several connections at once, then runs multiple files in parallel on top of that. The result is downloads that fill your pipe instead of trickling.

FEATURES
• Segmented, multi-connection downloads — one file across up to 32 parallel streams
• Parallel file transfers with a live queue: progress, speed and stream count per file, pause/resume, cancel and retry
• FTP, FTPS (explicit and implicit TLS) and SFTP over SSH, with password or private-key login
• Familiar dual-pane layout: local files on the left, remote on the right; drag selections across, multi-select, sort, right-click to rename, delete or create folders
• Recursive folder upload and download
• Site Manager for saved servers with default local and remote folders
• Adapts automatically to server connection limits — never fails a transfer because a server was busy
• VPN-aware: shows whether a Proton VPN or other VPN tunnel is active, launches your VPN app, and an optional kill switch holds transfers until the tunnel is up and stops them instantly if it drops
• Live bandwidth graph and full protocol log
• Dark, high-contrast interface that stays out of your way

ByteBouncer runs entirely on your PC. Server addresses and credentials you save stay on your machine; nothing is sent anywhere except to the servers you connect to.
