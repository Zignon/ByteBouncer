      Settings

      Bandwidth

      Large files are split into segments fetched over several connections at once, so one download can use the whole pipe even when the server limits speed per connection. Many servers cap connections per IP at 8–10; lower the totals if you see "too many connections" errors.

      VPN

      ByteBouncer watches your network adapters. With this on, transfers only run while a Proton VPN (or other VPN) tunnel is up; if the tunnel drops mid-transfer, active transfers stop immediately and resume automatically when it returns. ByteBouncer never sees your VPN login — use the official Proton VPN app.
